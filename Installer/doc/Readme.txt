========
MusBatch
========


----
概要

このインストーラは、「マウス・キーボード操作の記録と再生ツール」
MusBatch をインストールします。

インストールすると、GUI プログラムと CUI プログラムが指定した
インストール先フォルダに展開されます。

インストール後は、次のプログラムから起動します。

	GUI\GUI.exe


----
インストール先

既定のインストール先は次のフォルダです。

	%LOCALAPPDATA%\MusBatch

インストール先は、インストーラ画面の「参照」ボタンで変更できます。
ルートディレクトリを選択した場合は、フォルダ名 MusBatch が付与されます。

インストール先フォルダが既に存在し、MusBatch のインストール先として
確認できない場合は、上書き確認が表示されます。

再インストール時は、必要なプログラムフォルダとファイルを展開し直します。
インストール先フォルダそのものは削除して作り直しません。


----
デスクトップショートカット

インストール時に「デスクトップにショートカットを作成する」を選択すると、
デスクトップに次のショートカットを作成します。

	MusBatch.lnk

同名のショートカットが既に存在する場合は、上書き確認が表示されます。


----
インストールに必要なファイル

インストールには、Installer.exe と同じフォルダに次のファイルが必要です。

	GUI.cmp-gz
	GUI.cmp-gz.hash
	CUI.cmp-gz
	CUI.cmp-gz.hash

インストール前に、各クラスタファイルの SHA-512 ハッシュを確認します。
ファイルが存在しない場合、またはハッシュが一致しない場合は、
インストールを中止します。


----
アンインストール

既に MusBatch がインストールされているフォルダを指定すると、
インストーラ画面に「アンインストール」ボタンが表示されます。

アンインストールでは、指定されたインストール先フォルダ全体を削除します。
インストール先フォルダ内に個人用ファイルなどを置かないでください。

デスクトップに MusBatch.lnk が存在する場合は、削除するか確認します。


----
補足

インストール先フォルダが他のプログラムで使用されている場合、
インストールまたはアンインストールに失敗します。

Installer.exe は多重起動できません。
既に起動している場合は、先に起動しているインストーラを終了してください。
